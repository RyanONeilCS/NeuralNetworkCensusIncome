# Ryan O'Neil HW2 — Neural Networks

## Requirements / Libraries Used
Install these before running:

pip install ucimlrepo numpy pandas scikit-learn matplotlib

- ucimlrepo    - downloads the dataset from UCI
- numpy        - math / NaN handling
- pandas       - data tables and pre-processing
- scikit-learn - MLPClassifier, train/test split, StandardScaler, metrics
- matplotlib   - the model history plot

## Dataset
The Adult / Census Income dataset from the UCI Machine Learning Repository
(dataset ID 2). It is pulled directly from UCI at runtime using the ucimlrepo
package, so there is no dataset file to download and no local file paths are
hardcoded.

Dataset link: https://archive.ics.uci.edu/dataset/2/adult

## How to Run
Make sure the libraries above are installed, then run from the project folder:
    python NeuralNet.py

The script downloads the data, pre-processes it, trains all 24 models (one for every
combination of the hyperparameters), prints the per-model accuracy, prints the
full results table sorted by test accuracy and shows the model history plot. 
Close the plot window to let the programfinish. The plot is also saved as history_all.png.

## Modifications to the starter code
The starter header says I can modify the code as long as I mention it here.
What I changed:

- Data loading. Replaced pd.read_csv(dataFile) with fetch_ucirepo(id=2) so the
  dataset is pulled straight from UCI at runtime. This is why no local paths are
  hardcoded anywhere.
- preprocess(). Filled in the whole method (see Pre-Processing below).
- train_evaluate(). Filled in the four nested loops over the hyperparameters,
  the metric collection, the results table, and the plot.
- Added a StandardScaler after the train/test split (not before, to avoid
  leaking the test set into the scaling).
- Added random_state=42 to both train_test_split and MLPClassifier so the
  results are reproducible from run to run.
- Plot styling. The plot encodes activation by colour (blue = logistic,
  ornage = tanh, green = relu), learning rate by line style (solid = 0.01,
  dashed = 0.1), and hidden-layer count by opacity (solid = 2 layers,
  faded = 3 layers). I used ornage instead of red so the colours are still
  distinguishable for red-green colour blindness.

## Hyperparameters
All 24 combinations (3 x 2 x 2 x 2) were tested, using the values given in the
starter code:

- activation: logistic, tanh, relu   (MLPClassifier activation)
- learning rate: 0.01, 0.1           (MLPClassifier learning_rate_init)
- epochs: 100, 200                    (MLPClassifier max_iter)
- hidden layers: 2, 3                 (MLPClassifier hidden_layer_sizes)
